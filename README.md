# 🌍 WorldWise

A modern travel planning web application built with React.js that helps users keep track of the cities and countries they have visited.

## ✨ Features

- 🗺️ Interactive map for exploring travel destinations
- 📍 Display visited cities with interactive markers
- 🏙️ Dynamic city information and details
- 🔐 User authentication flow
- 🚪 Login and logout functionality
- 🧭 Client-side navigation with React Router
- 🌐 Global state management using Context API
- 📱 Responsive design
- ⚡ Dynamic rendering based on user interactions
- 🎨 Modular and reusable React components

## 🛠️ Technologies

- **React.js**
- **JavaScript (ES6+)**
- **React Router**
- **Context API**
- **CSS Modules**
- **Vite**
- **Leaflet / React Leaflet**
- **REST API**
